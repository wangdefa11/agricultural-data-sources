# `wiki.md` 修改说明与可复制模板

每个品种的人工内容都写在该品种自己的 `wiki.md`。例如大豆：

```text
content/commodities/soybean/wiki.md
```

不需要创建 `page.json` 或 `data.json`。页面从上到下的顺序，就是 `wiki.md`
从上到下的顺序。

## 1. 文件开头

每个 `wiki.md` 都从下面的文件头开始：

```markdown
---
slug: soybean
name: 大豆
codes: A · B · CBOT S
site_name: 农产品研究 Wiki
map_nav_label: 品种关系
breadcrumb_root_label: 品种关系
updated_prefix: 数据框架更新于
relations_link_label: 查看完整品种关系图 →
---
```

- `slug`：网址中的英文名称，必须与品种文件夹名一致；
- `name`：页面主标题；
- `codes`：标题旁的合约代码，可以删除；
- 其余字段是页面公共文字，一般不用修改。

需要显示更新时间时，增加：

```markdown
updated_at: 2026-08-01
```

## 2. 摘要和页面章节

```markdown
## 摘要

这里填写页面摘要。

## 01 宏观数据 {macro}

这里可以填写宏观章节的一句话说明。

## 02 日报数据 {daily}

这里可以填写日报章节的一句话说明。
```

- `##` 表示页面大章节；
- `01`、`02` 是页面显示的章节序号；
- `{macro}`、`{daily}` 是章节的稳定英文 id；
- `## 摘要` 必须保留；
- 增加新章节时，更换序号、标题和英文 id 即可。

## 3. 普通文字

在某个 `##` 章节下面添加：

```markdown
### 全球供给关注逻辑

这里填写第一段。

这里填写第二段。
```

`###` 是内容小标题，下面的空行用于分隔段落。

## 4. 链接和文字格式

```markdown
[USDA 数据](https://example.com)
[跳转到大豆页面](/soybean)
[跳转到本页宏观数据](#macro)
**加粗文字**
*斜体文字*
`seriesId`
```

这些格式可以写在摘要、正文、章节说明、表格单元格、检查清单、图表说明和图片
说明中。外部链接会在新标签页打开。

## 5. 普通表格

```markdown
### 需要关注的指标

| 指标 | 当前状态 | 编辑关注点 |
| --- | --- | --- |
| 美豆种植面积 | 在这里填写 | 在这里填写 |
| 巴西出口 | 在这里填写 | 在这里填写 |
```

直接增加或删除表头和数据行即可，每一行的列数应相同。

## 6. 图片

先把图片放进具体品种的 `images/` 文件夹，例如：

```text
content/commodities/soybean/images/soybean-calendar.png
```

然后在该品种 `wiki.md` 中写：

```markdown
### 全球大豆生长周期

![美国、巴西和阿根廷大豆生长周期](images/soybean-calendar.png)

这里填写图片来源、日期和口径。
```

支持 PNG、JPG、JPEG、WebP、GIF 和 AVIF。

## 7. 关键指标卡

```markdown
### 关键指标 {stats}

| 指标 | 数值 | 说明 | seriesId |
| --- | --- | --- | --- |
| 巴西产量 | 186.0 | 百万吨 · 2026/27预测 | br_soybean_production_y_usda_psd |
| 中国进口 | 115.0 | 百万吨 · 2026/27预测 | cn_soybean_imports_y_usda_psd |
```

`seriesId` 是底层数据的稳定名称。多个品种使用同一份数据时填写相同的
`seriesId`；暂时没有底层数据标识时可以留空。

## 8. 普通数据图表

```markdown
### 巴西与美国大豆产量 {chart}

说明：这里填写图表解释。
来源：这里填写来源和口径。

| 年度 | 巴西 | 美国 |
| --- | --- | --- |
| 24/25 | 172.5 | 119.0 |
| 25/26 | 180.0 | 116.0 |
```

纵轴起点、纵轴上限和无障碍说明都会根据标题与表格数据自动生成，不需要手工
填写。

需要在图表右上角显示最新数值时，可以增加：

```markdown
最新值：180.0 百万吨
```

## 9. 检查清单

```markdown
### 每日日报检查顺序 {checklist}

| 项目 | 说明 |
| --- | --- |
| 外盘与天气 | 这里填写检查内容。 |
| 进口成本 | 这里填写检查内容。 |
```

## 10. 独立交互图表

交互图表文件放在具体品种的 `charts/` 文件夹，然后在 `wiki.md` 写：

```markdown
### 大豆产业链全球供需结构 {embed}

说明：这里填写图表说明。
文件：charts/four-charts.html
链接文字：单独打开图表 ↗
```

嵌入高度会根据图表实际内容自动调整，不需要填写高度。

## 11. 关联品种

```markdown
## 03 关联品种 {relations}

这里填写关联品种说明。

### 关系顺序 {relations}

| 类型 | 内容 |
| --- | --- |
| node | soybean |
| label | 压榨 → |
| node | soymeal |
| label | 饲料 → |
| node | hog |
```

- `node` 后面填写 `catalog.json` 中已经登记的品种 slug；
- `label` 后面填写节点之间显示的关系文字。

## 12. 数据来源与口径

需要时在文件最后增加：

```markdown
## 数据来源与口径

这里填写官方来源、更新时间、单位、市场年度或自然年等口径说明。
```

不填写这个章节时，页面不会显示来源区域。

## 13. 模块宽度（可选）

一般不写宽度，内容默认占满正文。

确实需要两个模块并排时，可以在三级标题末尾添加：

- `{wide}`：左侧宽列；
- `{narrow}`：右侧窄列；
- `{full}`：占满正文。

例如：

```markdown
### 全国豆粕现货均价 {chart wide}

### 每日日报检查顺序 {checklist narrow}
```

## 14. 修改后查看

运行本地网站时会自动读取 `wiki.md`：

```bash
npm run dev
```

网站已经运行时，也可以手动更新内容：

```bash
npm run content:build
```

然后刷新浏览器页面。
