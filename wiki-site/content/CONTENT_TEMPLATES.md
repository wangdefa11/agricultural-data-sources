# `wiki.md` 修改说明与可复制模板

每个品种的人工内容都写在该品种自己的 `wiki.md`。例如大豆：

```text
content/commodities/soybean/wiki.md
```

不需要创建 `page.json` 或 `data.json`。页面从上到下的顺序，就是 `wiki.md`
从上到下的顺序。

## 0. 新建品种前先选择研究框架

新建品种 Wiki 时，不要直接从空白章节开始堆数据。先回答：

> 这个品种的边际供给来自哪里，货物怎样进入消费，变化最终怎样传导到期货价格？

根据答案选择一个主类型，再按需要增加辅助模块。同一个品种可以有多种属性，但必须有一条
明确的研究主线。

| 主类型 | 典型品种 | 页面重点 |
| --- | --- | --- |
| 全球贸易型 | 大豆、棕榈油、原糖、棉花 | 主产国、出口国、进口国、全球平衡表、贸易流与国际物流 |
| 国内生产型 | 豆1、花生、苹果、红枣 | 国内产区、面积与单产、物候期、上市节奏、品质和区域价差 |
| 进口依赖型 | 豆2、菜籽、部分油脂 | 国外供给、进口来源、到岸成本、港口库存、加工利润 |
| 国内外联动型 | 玉米、棉花、白糖 | 国内外平衡表并列，并解释内外价格传导的条件和阻隔 |
| 加工品型 | 豆粕、豆油、淀粉 | 原料成本、产出率、加工利润、开机、库存与下游消费 |
| 养殖型 | 生猪、鸡蛋 | 产能、存栏、生长周期、补栏与出栏、饲料成本 |
| 生鲜交割型 | 苹果、红枣 | 产区天气、坐果与品质、入库率、库存结构、交割标准 |

### 所有品种的共同研究主干

无论选择哪种母版，页面都应依次回答下列问题：

1. 交易的究竟是什么，现货、期货和替代品有何区别？
2. 主要在哪里生产，哪些区域决定边际供应？
3. 一年中什么时候形成面积、单产、产量和品质？
4. 供给怎样进入贸易、加工和流通？
5. 谁在消费，需求能否被其他原料或产品替代？
6. 库存存在哪里、由谁持有、何时可能进入市场？
7. 现货变化通过什么条件传导到基差、月差和期货价格？
8. 每日、每周、每月和每年分别需要跟踪什么？

推荐的共同章节顺序如下。母版可以调整标题，但不要打乱
“品种定义 → 生产 → 流通 → 消费 → 库存 → 定价 → 跟踪”的因果顺序。

```markdown
## 摘要
## 01 品种与合约 {overview}
## 02 产业链与价格形成 {pricing}
## 03 生产与产区 {production}
## 04 生育期与季节性 {calendar}
## 05 供需平衡 {balance}
## 06 贸易与物流 {trade}
## 07 加工、消费与替代 {demand}
## 08 库存与现货结构 {stocks}
## 09 政策、交割与风险 {policy}
## 10 研究指标与跟踪日历 {watchlist}
## 99 关联品种 {relations}
```

不适用的章节可以合并或缩短，但不能为了形式完整而填充无关内容。

### 全球贸易型母版

适用于边际供给主要来自海外、国际贸易决定价格的品种。`soybean/wiki.md`
可作为现有参考。

```markdown
## 01 品种概览 {overview}

### 现货、期货与主要用途
### 产业链和定价基准
### 核心研究问题

## 02 全球生产 {global-production}

### 全球生产格局 {stats}
### 主要生产国产量与份额 {chart full}
### 主产国产量变化来自面积还是单产

## 03 主产国拆解 {origins}

### 国家 A 主产区地图 {wide}
### 国家 A 物候与天气风险 {checklist narrow}
### 国家 A 面积、单产和产量 {chart full}
### 国家 B 主产区地图 {wide}
### 国家 B 物候与天气风险 {checklist narrow}

## 04 全球贸易 {trade}

### 主要出口国及份额 {chart wide}
### 主要进口国及份额 {chart narrow}
### 出口国到进口国的贸易流向
### 各出口国销售与装运季节性

## 05 全球消费与平衡表 {balance}

### 全球供需平衡表
### 消费用途拆分 {chart}
### 期末库存和库存消费比 {chart}

## 06 中国进口与国内传导 {china}

### 进口来源和到港季节性
### 到岸成本构成
### 港口、加工厂和国内库存

## 07 价格形成与跟踪 {pricing}

### 国际基准价格怎样传入国内
### 基差、月差和加工利润
### 报告日历 {checklist}
### 每日跟踪顺序 {checklist}
```

每个主要生产国应尽量具备同样的“三件套”：

- 主产区地图：标明实际面积或产量分布，不能用气候适宜区代替；
- 物候日历：标明播种、开花/授粉、结荚/膨果、灌浆和收获窗口；
- 产量趋势：同时展示面积、单产和产量，解释产量变化来源。

全球贸易部分应明确区分产量、可出口量、已销售量、已装船量和进口到港量。

### 国内生产型母版

适用于国内产区和新作上市节奏决定价格的品种。`soybean-no1/wiki.md`
可作为现有参考。

```markdown
## 01 品种与市场 {overview}

### 期货对应的现货和品质
### 产业链与研究主线
### 与进口品、替代品的区别

## 02 国内产区与产量 {production}

### 实际生产分布图 {wide}
### 主要产区跟踪清单 {checklist narrow}
### 全国和主产省面积、单产、产量 {chart full}
### 总产量怎样转化为有效供应

## 03 生物学与物候 {biology}

### 生物学特性
### 分产区物候日历 {chart}
### 关键生育阶段与天气风险
### 天气影响验证顺序 {checklist}

## 04 上市、流通与库存 {circulation}

### 新作上市日历
### 农户、贸易商、加工企业和政策库存
### 产区到消费区的物流和区域价差

## 05 用途、消费与替代 {demand}

### 下游用途与品质要求
### 主要加工企业和消费区域
### 替代品比价和替代条件

## 06 品质、交割与政策 {delivery}

### 商品等级与市场主流品质
### 期货交割标准和升贴水
### 交割库分布与可交割量
### 收储、轮出、补贴和进口政策

## 07 价格形成与跟踪 {pricing}

### 产区现货怎样传导到期货
### 基差、月差、仓单和持仓
### 每日跟踪顺序 {checklist}
```

国内产量必须按下面的链条解释，不能把统计总产量直接等同于期货有效供应：

```text
种植收益 → 播种面积 → 生育期天气 → 单产 → 质量等级
→ 商品粮数量 → 可流通量 → 可交割量
```

“种植适宜区图”和“实际产量分布图”是两种不同地图。前者解释生物学边界，后者解释
现实供应权重；需要时应分别展示并分别注明来源。

### 加工品型母版

加工品的逻辑不是简单复制原料页，而要回答“加工意愿”和“产出如何被下游消化”。

```markdown
## 01 产品与产业链 {overview}
## 02 原料供给和采购成本 {raw-material}
## 03 加工工艺、产出率和产能分布 {processing}
## 04 加工利润、开机和产量 {margin}
## 05 下游用途、消费和替代 {demand}
## 06 工厂库存、渠道库存和提货 {stocks}
## 07 进出口与区域流向 {trade}
## 08 现货、基差、月差和价格传导 {pricing}
## 09 每日跟踪顺序 {watchlist}
```

加工链应至少完整展示一次：

```text
原料到厂成本 → 加工利润 → 开机率 → 产品产量
→ 工厂库存 → 成交和提货 → 下游库存 → 现货与基差
```

开机或产量增加不能直接写成需求改善，必须用库存、成交、提货或终端消费验证。

### 养殖型和生鲜交割型的附加模块

养殖品种需要增加：

- 生物资产从补栏到出栏的时间轴；
- 能繁或后备产能、存栏、出栏体重和淘汰节奏；
- 饲料成本、养殖利润、疫病和政策冻储；
- 现货价格、区域价差和期货合约对应时间的错配。

生鲜交割品种需要增加：

- 分产区萌芽、开花、坐果、膨果、成熟和采收日历；
- 产量、商品率、优果率、规格和等级的逐层转换；
- 入库量、出库量、库容、库存质量和持货主体；
- 交割标准、交割库、替代交割品和升贴水。

### 地图和日历的最低要求

地图不是装饰图片，每张地图都必须回答一个明确问题：

| 地图或日历 | 必须回答的问题 |
| --- | --- |
| 全球生产分布图 | 供应集中在哪些国家 |
| 国家主产区地图 | 哪些区域的天气决定边际产量 |
| 国内产量分布图 | 哪些省份决定现实供应 |
| 适宜种植区图 | 作物的气候和品种边界在哪里 |
| 分产区物候日历 | 当前天气影响哪个地区、哪个阶段 |
| 贸易流向图 | 货物从哪里运往哪里 |
| 港口、加工厂或冷库地图 | 物流、加工或库存瓶颈在哪里 |
| 交割库地图 | 现货通过哪些地点进入期货市场 |

地图图注必须写明数据年份、指标口径、作者或制图机构、原始数据机构和许可信息。
不得使用 AI 生成的作物实景图片。

### 最终必须落到价格验证链

页面不能停留在百科知识和静态数据，最后必须给出该品种的价格验证链。例如：

```text
天气或政策变化 → 面积/单产/品质变化 → 可出口量或可流通量变化
→ 到港/库存/加工变化 → 现货和基差变化 → 期货价格和月差反应
```

同时将指标分为三类：

| 频率 | 典型指标 | 用途 |
| --- | --- | --- |
| 慢变量 | 面积、产能、消费结构、长期政策 | 确定年度供需方向 |
| 中频变量 | 月度产量、进出口、加工量、库存 | 验证供需兑现速度 |
| 高频变量 | 天气、进度、装船、到港、开机、成交、基差、仓单 | 判断交易节奏和预期差 |

每个数据、图表和图片的来源仍须遵守下文的内容块规则，紧跟对应内容，不得统一堆放在
页面底部。

## 1. 文件开头

每个 `wiki.md` 都从下面的文件头开始：

```markdown
---
slug: soybean
name: 大豆
codes: A · B · CBOT S
site_name: 农产品研究 Wiki
map_nav_label: 品种关系
breadcrumb_root_label: 品种关系
updated_prefix: 数据框架更新于
relations_link_label: 查看完整品种关系图 →
---
```

- `slug`：网址中的英文名称，必须与品种文件夹名一致；
- `name`：页面主标题；
- `codes`：标题旁的合约代码，可以删除；
- 其余字段是页面公共文字，一般不用修改。

需要显示更新时间时，增加：

```markdown
updated_at: 2026-08-01
```

## 2. 摘要和页面章节

```markdown
## 摘要

这里填写页面摘要。

## 01 宏观数据 {macro}

这里可以填写宏观章节的一句话说明。

## 02 日报数据 {daily}

这里可以填写日报章节的一句话说明。
```

- `##` 表示页面大章节；
- `01`、`02` 是页面显示的章节序号；
- `{macro}`、`{daily}` 是章节的稳定英文 id；
- `## 摘要` 必须保留；
- 增加新章节时，更换序号、标题和英文 id 即可。

## 3. 普通文字

在某个 `##` 章节下面添加：

```markdown
### 全球供给关注逻辑

这里填写第一段。

这里填写第二段。
```

`###` 是内容小标题，下面的空行用于分隔段落。

## 4. 链接和文字格式

```markdown
[USDA 数据](https://example.com)
[跳转到大豆页面](/soybean)
[跳转到本页宏观数据](#macro)
**加粗文字**
*斜体文字*
`seriesId`
```

这些格式可以写在摘要、正文、章节说明、表格单元格、检查清单、图表说明和图片
说明中。外部链接会在新标签页打开。

## 5. 普通表格

```markdown
### 需要关注的指标

| 指标 | 当前状态 | 编辑关注点 |
| --- | --- | --- |
| 美豆种植面积 | 在这里填写 | 在这里填写 |
| 巴西出口 | 在这里填写 | 在这里填写 |
```

直接增加或删除表头和数据行即可，每一行的列数应相同。

## 6. 图片

先把图片放进具体品种的 `images/` 文件夹，例如：

```text
content/commodities/soybean/images/soybean-calendar.png
```

然后在该品种 `wiki.md` 中写：

```markdown
### 全球大豆生长周期

![美国、巴西和阿根廷大豆生长周期](images/soybean-calendar.png)

这里填写图片来源、日期和口径。
```

支持 PNG、JPG、JPEG、WebP、GIF 和 AVIF。

## 7. 关键指标卡

```markdown
### 关键指标 {stats}

| 指标 | 数值 | 说明 | seriesId |
| --- | --- | --- | --- |
| 巴西产量 | 186.0 | 百万吨 · 2026/27预测 | br_soybean_production_y_usda_psd |
| 中国进口 | 115.0 | 百万吨 · 2026/27预测 | cn_soybean_imports_y_usda_psd |
```

`seriesId` 是底层数据的稳定名称。多个品种使用同一份数据时填写相同的
`seriesId`；暂时没有底层数据标识时可以留空。

## 8. 普通数据图表

```markdown
### 巴西与美国大豆产量 {chart}

说明：这里填写图表解释。
来源：这里填写来源和口径。

| 年度 | 巴西 | 美国 |
| --- | --- | --- |
| 24/25 | 172.5 | 119.0 |
| 25/26 | 180.0 | 116.0 |
```

纵轴起点、纵轴上限和无障碍说明都会根据标题与表格数据自动生成，不需要手工
填写。

需要在图表右上角显示最新数值时，可以增加：

```markdown
最新值：180.0 百万吨
```

## 9. 检查清单

```markdown
### 每日日报检查顺序 {checklist}

| 项目 | 说明 |
| --- | --- |
| 外盘与天气 | 这里填写检查内容。 |
| 进口成本 | 这里填写检查内容。 |
```

## 10. 独立交互图表

交互图表文件放在具体品种的 `charts/` 文件夹，然后在 `wiki.md` 写：

```markdown
### 大豆产业链全球供需结构 {embed}

说明：这里填写图表说明。
文件：charts/four-charts.html
链接文字：单独打开图表 ↗
```

嵌入高度会根据图表实际内容自动调整，不需要填写高度。

## 11. 关联品种

```markdown
## 03 关联品种 {relations}

这里填写关联品种说明。

### 关系顺序 {relations}

| 类型 | 内容 |
| --- | --- |
| node | soybean |
| label | 压榨 → |
| node | soymeal |
| label | 饲料 → |
| node | hog |
```

- `node` 后面填写 `catalog.json` 中已经登记的品种 slug；
- `label` 后面填写节点之间显示的关系文字。

## 12. 数据来源与口径

需要时在文件最后增加：

```markdown
## 数据来源与口径

这里填写官方来源、更新时间、单位、市场年度或自然年等口径说明。
```

不填写这个章节时，页面不会显示来源区域。

## 13. 模块宽度（可选）

一般不写宽度，内容默认占满正文。

确实需要两个模块并排时，可以在三级标题末尾添加：

- `{wide}`：左侧宽列；
- `{narrow}`：右侧窄列；
- `{full}`：占满正文。

例如：

```markdown
### 全国豆粕现货均价 {chart wide}

### 每日日报检查顺序 {checklist narrow}
```

## 14. 修改后查看

运行本地网站时会自动读取 `wiki.md`：

```bash
npm run dev
```

网站已经运行时，也可以手动更新内容：

```bash
npm run content:build
```

然后刷新浏览器页面。
