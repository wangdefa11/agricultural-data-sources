## 摘要

红枣期货交易的是经过加工和品质筛选的干制灰枣，不是全部鲜枣或所有枣类，郑州商品交易所红枣期货代码为 CJ。国内供应高度集中于新疆，价格沿"枣园管理与天气 → 灰枣产量和品质 → 收购与初加工 → 成品等级和库存 → 销区消费 → 可交割货源"传导。总产量只有经过粒数、均匀度、总糖、含水率、杂质、缺陷果和加工厂筛选后，才可能成为期货有效供应。

研究红枣必须特别注意数据口径：公开资料中"全国红枣产量"存在全口径、干重口径和灰枣口径等多套数字，彼此差异巨大且不能混用。期货研究应以新疆灰枣产量和加工成品量为主线，全国总量只作为背景参考。

### 红枣的价格传导主线 {wide}

**花期天气与坐果 → 膨大期管理与裂果 → 灰枣产量和含水率 → 采收、晾晒与初加工 → 成品率与等级分布 → 加工厂和销区库存 → 节庆消费与现货 → 可交割货源、基差与期货价格**

这条链上有两个红枣特有的转换。一是鲜果到干品：干制损耗使成品重量远小于鲜果产量，且含水率既是质量指标又是交割变量。二是统货到等级货：同一批货经粒数分级后，各等级的价格可以独立运行，特级与低等级的价差有时比均价方向更重要。

### 红枣研究主线 {checklist narrow}

| 环节 | 重点问题 |
|---|---|
| 天气 | 干热风、连阴雨影响坐果还是裂果？ |
| 产量 | 用的是全口径、干重还是灰枣口径？ |
| 加工 | 成品率和等级分布处于什么水平？ |
| 库存 | 原料枣、统货、成品和仓单各有多少？ |
| 消费 | 节庆备货是提前发生还是当下动销？ |
| 价格 | 等级价差、基差、月差和仓单是否相互验证？ |

## 02 产区、品种与有效供应 {production}

新疆是国内红枣最重要的生产供给基地，南疆环塔里木盆地形成大规模灰枣、骏枣种植和加工带，产量约占全国一半，且以干制枣为主；陕西、山西、河北、山东等传统产区逐步转向鲜食和特色品种。期货基准品为灰枣，因此全口径红枣产量不能直接替代灰枣商品量；同样，鲜果产量也不能直接替代干制后成品重量。

### 从统计产量到可交割量 {wide}

| 层级 | 需要扣除或区分 |
|---|---|
| 枣园产量 | 非灰枣品种、落果和未采收果 |
| 鲜果商品量 | 水分损耗、裂果、病虫果和不熟果 |
| 加工成品 | 粒数分级、总糖、含水率、杂质和外观缺陷 |
| 期货可交割量 | 指定厂家、包装、交割地点、等级与仓单期限 |

### 产量口径必须分清 {full}

公开资料中的红枣产量至少有三套口径：全口径鲜枣及干枣合计（2022年约747万吨）、干重口径（明显更低）、以及期货研究最需要的灰枣口径（例如行业机构初步统计2024产季新疆灰枣产量约56万吨，较上年增产约六成，属估算值）。三套数字差异巨大，红枣适应性强、大幅减产年份少，"产量"本身很少是行情主线，品质、等级结构和加工节奏才是。

## 03 生长季、收获与加工 {calendar}

红枣研究不能只盯采收期。花期天气决定坐果，膨大期管理影响粒数等级，采收期降雨影响裂果和含水率，收后加工又决定期货等级分布。新疆主产区的关键窗口是初夏的干热风和秋季的采收期降雨。

### 生长季日历 {wide}

| 阶段 | 典型窗口 | 核心风险 |
|---|---|---|
| 萌芽展叶 | 春季 | 倒春寒、树势和灌溉 |
| 开花坐果 | 初夏 | 高温、干热风、降雨和授粉坐果 |
| 果实膨大 | 夏季 | 灌溉、裂果、病虫害和大小均匀度 |
| 转色成熟 | 秋季 | 早霜、降雨、糖分积累和含水率 |
| 采收晾晒 | 秋末 | 连阴雨、霉变和采收进度 |
| 初加工与分级 | 收获后 | 干制损耗、粒数、糖度、含水率和成品率 |

### 天气验证顺序 {checklist narrow}

| 项目 | 先问什么 |
|---|---|
| 干热风 | 发生在花期还是膨大期，持续几天？ |
| 采收降雨 | 影响裂果率还是晾晒进度？ |
| 早霜 | 影响糖分积累还是采收窗口？ |
| 验证 | 坐果、裂果、含水率调研是否确认？ |

### 季节性资料来源 {source}

南疆主产区的天气、坐果和采收进度来自行业机构产区调研和地方农业气象公开资料，引用时必须注明调研时间和样本区域（若羌、阿克苏、喀什等产区差异明显）。

## 04 收购、加工与流通 {circulation}

产区货物从枣农、合作社进入收购商和加工厂，经清洗、烘干或晾晒、分级、包装后，再流向新疆及内地仓库、批发市场、电商和食品加工企业。盘面影响收购预期，但加工厂实际采购还取决于成品率、订单、资金和库存。

### 流通观察位置 {wide}

| 观察位置 | 关键指标 |
|---|---|
| 枣园与收购点 | 开秤价、采收进度、统货质量和农户惜售 |
| 加工厂 | 原料库存、加工量、成品率和各等级库存 |
| 销区市场 | 到货、成交、等级价差和渠道库存 |
| 期货交割 | 仓单、预报、指定厂库、车板货源和升贴水 |

### 流通检查清单 {checklist narrow}

| 情形 | 先检查什么 |
|---|---|
| 开秤价高开 | 减产预期、客商抢货还是成本推动？ |
| 加工量偏低 | 原料不足、成品率低还是订单不足？ |
| 销区到货增加 | 需求承接还是产区被动出货？ |
| 仓单增加 | 现货滞销转交割还是套保需求？ |

### 流通资料来源 {source}

开秤价、加工厂收购、成品率和销区到货数据来自行业机构调查，引用时必须注明产区样本、等级标准和统计频率；红枣及制品进出口使用[海关总署](https://www.customs.gov.cn/)数据，但进出口占比很小，主要影响局部情绪。

## 05 消费、库存与价格 {demand}

红枣以直接食用为主，也进入礼品、电商、商超、餐饮及枣泥、枣浆、饮品等加工。消费具有鲜明的节庆和秋冬季特征——每年10月至次年3月是传统销售旺季，但备货通常提前发生。高低等级之间并非完全替代：礼品和精品渠道更重外观与规格，加工需求更关注成本、糖度和出成率。

### 库存分层 {wide}

| 库存位置 | 市场含义 | 重点观察 |
|---|---|---|
| 原料枣 | 未加工统货 | 产区存量、含水率变化 |
| 加工厂成品 | 已分级等级货 | 各等级库存结构 |
| 销区渠道 | 批发、电商和商超库存 | 走货速度、补库节奏 |
| 交割仓单 | 可交割显性供应 | 注册、注销、年份和等级 |

### 消费验证清单 {checklist narrow}

| 顺序 | 验证问题 |
|---|---|
| 备货 | 节庆备货提前多久启动，力度如何？ |
| 走货 | 销区好转是补库还是终端动销？ |
| 等级 | 好货与低等级货的价差是走扩还是收窄？ |
| 替代 | 时令水果和其他干果是否形成挤压？ |

### 库存解读要点

库存数量上升是否形成压力，还取决于等级、年份、含水率、货权和持有成本。陈枣与新枣、高等级与低等级不能加总为一个"总库存"来解读。

## 06 政策与事件传导 {policy}

### 政策和事件怎样传导 {full}

| 政策或事件 | 首先影响 | 后续验证 |
|---|---|---|
| 交割规则调整 | 可交割货源范围和成本 | 仓单、近月基差和交割量 |
| 新疆林果产业政策 | 长期面积和加工布局 | 新植、改造和加工产能 |

| 出口检疫和准入 | 好货分流方向 | 出口量和等级价差 |

## 07 价格验证与每日跟踪 {watchlist}

红枣行情分两段：生长季（5—10月）交易坐果和品质预期，加工消费季（10月—次年）交易成品率、库存结构和节庆消费。红枣减产年份少，多数行情的主线是品质分化、加工节奏和库存结构，而不是总量。

### 价格验证链 {wide}

**天气与管理变化 → 产量、裂果率和含水率变化 → 成品率和等级分布变化 → 加工、库存和备货节奏变化 → 等级现货和价差变化 → 基差、月差、仓单与期货价格反应**

如果盘面上涨而销区走货平淡、加工厂库存充足，涨价可能更多由天气题材或资金推动；如果盘面下跌但特级货价格坚挺、仓单持续注销，则好货的结构性紧张可能尚未被充分定价。红枣的干热风炒作历史上多次落空，题材必须用坐果和裂果调研验证。

### 指标按频率分层 {full}

| 频率 | 指标 | 用途 |
|---|---|---|
| 慢变量 | 面积、品种结构、加工产能、消费习惯 | 确定年度供需方向 |
| 产季内 | 坐果、裂果、含水率、成品率调研 | 修正产量和品质预期 |
| 月度/周度 | 加工量、各等级库存、销区走货、仓单 | 判断现货松紧节奏 |
| 日度 | 等级现货报价、基差、月差、升贴水和持仓 | 识别预期差与交易驱动 |

### 每日跟踪 {checklist full}

| 顺序 | 检查 |
|---|---|
| 1 | 南疆天气、坐果、膨大、成熟和采收进度 |
| 2 | 统货开秤价、加工厂收购、成品率和等级分布 |
| 3 | 产区与销区现货、到货、成交和库存 |
| 4 | 仓单、交割预报、厂库报价和等级升贴水 |
| 5 | 基差、月差、持仓及合约对应货源年份 |

### 研究口径来源 {source}

国内期货、仓单和交割数据使用[郑州商品交易所](https://www.czce.com.cn/)资料；产量趋势使用国家林业和草原局及统计年鉴口径。所有行业调研数据都应注明机构、产季和估算方法，避免不同口径数字互相引用。

## 99 关联品种 {relations}

红枣与苹果同为生鲜交割品种，研究方法可以互相参照（坐果品质、加工/入库率、等级结构三层筛选）；与其他干果和时令水果存在消费替代。红枣是郑商所品种中供应最集中的之一，南疆单一产区的天气和加工节奏就能决定全局。
