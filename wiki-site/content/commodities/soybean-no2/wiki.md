## 摘要

豆2是大连商品交易所黄大豆2号期货，研究对象更接近进口压榨大豆。它的一端连接巴西、美国和阿根廷的生产、出口升贴水与船期，另一端连接中国港口、油厂压榨、豆粕饲用和豆油消费。

分析豆2时，应沿着“国际产地供给 → 出口报价与海运 → 中国到港成本 → 油厂原料库存与压榨 → 豆粕、豆油库存和提货”逐层验证。豆2不是 CBOT 大豆的人民币简单换算，进口增加也不能直接写成需求改善。

## 01 品种概览 {overview}

豆2处于全球大豆定价和中国油厂加工之间。全球产量决定供应底盘，产地升贴水决定货源竞争，汇率、海运和税费决定进口成本，压榨利润与产品库存决定油厂是否愿意继续采购和开机。

### 豆2的价格传导主线 {wide}

豆2的研究起点不是国内种植面积，而是中国能够从国际市场取得多少具备价格竞争力的压榨大豆。主产国增产只有转化为可出口量，并通过升贴水、装船和海运进入中国，才会改变国内原料供给。

到港以后还要继续验证。油厂原料增加可能带来更高开机，也可能形成库存压力；压榨量增加只有被豆粕和豆油成交、提货及终端消费吸收，才代表需求真正改善。

### 三个市场不能机械换算

CBOT反映全球大豆预期，但中国实际进口成本还受到产地升贴水、海运费、人民币汇率、关税和船期影响。CBOT下跌时，若巴西升贴水走强或人民币贬值，中国到岸成本未必同步下降。

豆1和豆2也不是同一种现货。豆1更接近国产非转基因食用豆，豆2更接近进口压榨链。两者只有在用途允许替代、质量和监管合规且下游愿意调整配方时，价差才可能带来真实替代。

## 02 全球生产与季节性 {global}

全球大豆供应集中在巴西、美国和阿根廷。豆2研究不仅要看三个国家产量之和，更要看产量怎样转化为出口：巴西和美国直接影响中国原豆采购，阿根廷国内压榨工业则会在原豆、豆粕和豆油出口之间分流供应。

## 03 中国进口与价格形成 {imports}

### 进口大豆成本链 {wide}

进口成本应匹配采购月份、产地和船期：

**CBOT对应月份期货 + 产地基差/升贴水 + 海运费和保险 → 美元到岸价格 × 美元兑人民币汇率 + 关税、增值税、港杂和资金成本 → 人民币到岸完税成本**

CBOT、升贴水、汇率和海运费可能相互抵消。比较豆2盘面与进口成本时，必须使用同船期、同质量和同税费条件，不能把当日近月盘面与远月船货直接比较。

### 成本检查清单 {checklist narrow}

| 项目 | 常见误判 |
|---|---|
| CBOT | 期货上涨就等同到岸成本同比例上涨 |
| 升贴水 | 忽略期货下跌时产地现货可能走强 |
| 海运 | 用一个运费覆盖不同港口和船期 |
| 汇率 | 只看美元指数而不看实际人民币汇率 |
| 税费 | 沿用历史税率或忽略原产地差异 |

### 进口与成本资料来源 {source}

分来源月度进口量使用 [海关总署](https://www.customs.gov.cn/) 统计，进口准入和检验检疫也以海关总署公告为准；关税使用国务院关税税则委员会和财政部现行文件。CBOT规则以 CME Group 为准，产地升贴水、海运和汇率图表必须注明报价日期、产地和船期。

## 04 压榨、产品与需求 {crush}

进口大豆主要进入油厂，同时产出豆粕和豆油。油厂的真实加工意愿取决于两个产品的综合价值、原料成本、库存压力、合同执行和停机安排。

### 压榨传导逻辑 {wide}

**进口大豆到厂成本 → 盘面或现货压榨利润 → 油厂采购和开机 → 豆粕、豆油产量 → 工厂库存 → 成交和提货 → 下游库存与消费**

豆油上涨可能改善压榨利润并提高开机，从而增加豆粕供应；因此豆油走强并不一定同步利多豆粕。压榨量上升也不等于终端需求改善，必须继续检查产品库存、成交和提货。

### 压榨研究主线 {checklist narrow}

| 环节 | 观察重点 |
|---|---|
| 原料 | 油厂大豆库存、到港和采购覆盖天数 |
| 加工 | 压榨利润、开机、压榨量和停机计划 |
| 豆粕 | 库存、成交、提货和饲料配方 |
| 豆油 | 库存、成交、油脂价差和消费季节性 |
| 养殖 | 存栏、利润、饲料产量和豆粕添加比例 |

### 进口增加之后怎么验证 {full}

| 顺序 | 验证问题 | 偏宽松的表现 | 偏紧张的表现 |
|---|---|---|---|
| 到港 | 船货是否按时卸港 | 到港集中、通关顺畅 | 延误、压港或准入受限 |
| 原料库存 | 油厂覆盖天数怎样变化 | 库存累积、催开机 | 库存下降、停机待豆 |
| 压榨 | 开机是否真正增加 | 高开机、压榨增加 | 开机受限、压榨下降 |
| 产品库存 | 产出能否被消化 | 豆粕豆油库存累积 | 库存下降、提货加快 |
| 现货 | 压力是否进入价格 | 基差走弱、区域价差收窄 | 基差走强、近月偏紧 |

### 压榨数据来源 {source}

年度压榨消费采用农业农村部 CASDE 大豆供需平衡表。周度开机、压榨、成交、提货和商业库存属于行业高频数据，引用时必须注明数据提供方、样本范围、发布日期及是否为估算值，不能与官方年度平衡表混为同一口径。

## 05 库存、政策与跟踪 {storage}

豆2库存必须按位置和所有者拆分。相同数量的大豆停留在在途船货、港口、油厂原料仓或交割库，对近月价格和开机节奏的影响不同。

### 库存必须分位置 {wide}

| 库存位置 | 价格含义 | 重点观察 |
|---|---|---|
| 在途船货 | 未来到港供应 | 船期、延误和目的港 |
| 港口库存 | 已到岸但未必可立即压榨 | 通关、检验、货权和疏港 |
| 油厂原料库存 | 未来开机保障 | 覆盖天数、合同和停机计划 |
| 豆粕豆油库存 | 压榨产出的消化结果 | 库存方向、成交和提货 |
| 期货仓单 | 可进入交割的显性供应 | 注册、注销、库点和质量 |

### 政策风险怎样传导 {full}

| 政策或事件 | 首先影响 | 后续验证 |
|---|---|---|
| 关税调整 | 不同原产地完税成本 | 采购来源、升贴水和船期是否切换 |
| 检验检疫 | 企业或产地准入、通关速度 | 卸港、压港和油厂原料库存 |
| 转基因审批 | 可进口品种范围 | 采购合同和到港执行 |
| 储备采购或投放 | 市场可见供需和预期 | 实际成交、入库或出库 |
| 生物柴油政策 | 主产国豆油需求和压榨 | 原豆可出口量和豆油价值 |
| 出口政策 | 出口国农户售粮意愿 | 离岸报价和装船量 |

### 每日跟踪顺序 {checklist full}

| 顺序 | 检查内容 |
|---|---|
| 外盘 | CBOT涨跌来自天气、宏观、基金还是出口？ |
| 产地 | 巴西和美国升贴水是否抵消期货变化？ |
| 成本 | 汇率、海运和税费后的到岸成本如何变化？ |
| 到港 | 近月到港、港口库存和油厂原料是否宽松？ |
| 压榨 | 利润、开机和豆粕豆油库存是否相互确认？ |
| 现货 | 豆2、豆粕和豆油基差是否确认供需变化？ |
