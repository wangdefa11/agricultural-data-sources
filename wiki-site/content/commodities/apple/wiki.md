## 摘要

苹果是多年生果树和生鲜交割品，郑州商品交易所苹果期货代码为 AP。单一年度供应由挂果面积、树龄结构、花期坐果、套袋与管理、采前天气共同决定，收获后又被果径、着色、糖度、硬度、缺陷和入库率重新筛选。期货对应的是符合国标一等及以上等级的红富士，与统计产量之间隔着多层转换。

研究苹果不能把全国产量直接当作期货货源。更可靠的验证链是"花量与坐果 → 套袋和果径 → 产量与优果率 → 开秤收购与入库率 → 冷库库存与出库 → 销区消费与替代水果 → 可交割货源、基差和期货价格"。苹果一年一收，生长季的天气决定当年供应，冷库库存决定收获后到次年清库之间的供应节奏。

### 苹果的价格传导主线 {wide}

**花期天气与坐果 → 套袋数量与果径 → 产量与优果率 → 开秤价与入库率 → 冷库库存结构 → 出库节奏与销区走货 → 现货等级价差 → 基差、月差与期货价格**

这条链上有两个苹果特有的转换。一是生长季到收获：天气影响的不是"产量"一个数字，而是产量与优果率的组合，丰产减质和减产增质的价格含义完全相反。二是收获到消费：一年一收的作物要靠冷库库存撑一年，入库率和出库节奏决定每个合约月份的实际货源。

### 苹果研究主线 {checklist narrow}

| 环节 | 重点问题 |
|---|---|
| 天气 | 霜冻、冰雹影响哪个产区、多大比例的果园？ |
| 产量 | 套袋调研与最终产量差异有多大？ |
| 质量 | 优果率、果径和糖度处于什么水平？ |
| 入库 | 入库率高是丰产还是现货卖不动？ |
| 出库 | 出库加快是需求好还是降价去库？ |
| 价格 | 等级价差、基差、月差和仓单是否相互验证？ |

## 02 产区、树龄与有效供应 {production}

国内苹果生产形成黄土高原、渤海湾两大优势产区，重点跟踪陕西、山东、甘肃、山西、河南、辽宁等省份。据国家统计局数据，2024年陕西产量1449.9万吨、山东1073.9万吨、甘肃538.9万吨，三省合计约占全国六成。全国苹果产量并不等于红富士商品量，更不等于期货可交割量；产区品种结构、果园树龄和优果率比单一总产量更接近边际定价。

### 从统计产量到可交割量 {wide}

| 层级 | 主要筛选 |
|---|---|
| 全部苹果产量 | 品种、产区和商品化率 |
| 红富士商品果 | 果径、着色、果面和损伤 |
| 入库果 | 硬度、糖度、耐储性和采购成本 |
| 期货货源 | 质量容许度、指定地点、检验和交割月份 |

### 产量口径必须分清 {full}

国家统计局2024年苹果产量为5128.5万吨，而商业机构按套袋调研估算的同期产量明显更低（约3600—3900万吨区间）。这不是谁对谁错的问题：统计局口径覆盖全部苹果品种和产区，商业套袋调研聚焦晚熟红富士商品果。研究期货货源时应以商业调研跟踪边际变化，以统计局数据锚定长期趋势，并始终注明使用的是哪一套口径。

## 03 生长季与天气风险 {calendar}

苹果是多年生作物，当年供应在花期到采收的几个月内逐步定型。倒春寒影响坐果，冰雹影响果面，采收前降雨影响着色和糖度——同样的天气发生在不同生育阶段，对产量和品质的影响完全不同。

### 生长季日历 {wide}

| 阶段 | 典型时间 | 关键影响 |
|---|---|---|
| 休眠与修剪 | 冬季 | 低温冻害、树势和花芽基础 |
| 萌芽开花 | 春季 | 倒春寒、授粉天气和花量 |
| 坐果疏果 | 春末初夏 | 坐果率、疏果强度和套袋数量 |
| 果实膨大 | 夏季 | 降水、冰雹、高温和病虫害 |
| 着色成熟 | 秋季 | 温差、日照、降雨、果径和糖度 |
| 采收入库 | 秋季至初冬 | 采收节奏、收购价、硬度和入库率 |

### 天气验证顺序 {checklist narrow}

| 项目 | 先问什么 |
|---|---|
| 霜冻 | 发生在花期还是幼果期，受灾园比例多少？ |
| 冰雹 | 影响果面（质量）还是落果（产量）？ |
| 连阴雨 | 影响着色糖度还是采收进度？ |
| 验证 | 花量、坐果、套袋、果径数据是否确认？ |

### 天气事件怎样核实

天气事件必须通过花量、坐果、套袋、果径和优果率验证。一次霜冻或冰雹影响的范围、持续时间和受灾园比例，比新闻标题本身更重要。

## 04 收购、冷库与出库 {stocks}

新果采收后，一部分直接进入销区，另一部分由果农、果商、代办和冷库采购入库。入库量增加可能来自丰产，也可能来自现货销售不畅；出库加快可能代表需求改善，也可能是持货方降价去库。库存必须分货权、分质量、分成本来看。

### 库存流转环节 {wide}

| 阶段 | 跟踪指标 |
|---|---|
| 开秤收购 | 统货与好货价格、果农惜售、客商数量 |
| 入库 | 入库率、库容、货权、采购成本和质量 |
| 储存 | 硬度衰减、损耗、资金和仓储成本 |
| 出库 | 周度出库、成交价、剩余库存和替代水果 |
| 清库 | 库龄、质量分化、旧作与新作衔接 |

### 库存变化检查清单 {checklist narrow}

| 情形 | 先检查什么 |
|---|---|
| 入库率偏高 | 丰产、客商积极还是果农被动入库？ |
| 出库偏慢 | 需求差、价格高还是替代水果冲击？ |
| 好货涨价 | 优果率低还是礼盒需求集中？ |
| 次果滞销 | 质量问题还是加工果承接不足？ |
| 清库压力 | 剩余库存的库龄和质量能否撑到新果？ |

### 库存资料来源 {source}

冷库库存、出库速度、开秤价和客商数据来自商业机构调查，引用时必须注明产区样本（如山东栖霞、陕西洛川等标志性产区）、统计频率和货权口径；不同机构库存样本不同，不能直接互比。

## 05 消费、替代与价格 {demand}

鲜食是主要需求，商超、电商、批发市场、礼品和家庭渠道对果径、外观和包装要求不同。柑橘、梨、葡萄及其他时令水果通过相对价格形成替代。加工果汁等需求能够消化低等级果，但通常不能直接承接高价交割品。

### 需求线索 {wide}

| 渠道 | 需求特征 | 重点指标 |
|---|---|---|
| 批发市场 | 走量主体，价格风向标 | 到货量、成交价、走货速度 |
| 商超电商 | 分级分价，品质敏感 | 果径等级价差、礼盒动销 |
| 节日礼品 | 脉冲式，偏好大果好货 | 春节、中秋备货节奏 |
| 加工 | 消化低等级果 | 果汁厂收购价、开机 |

### 需求验证清单 {checklist narrow}

| 顺序 | 验证问题 |
|---|---|
| 走货 | 销区好转是补库还是终端动销？ |
| 替代 | 柑橘、梨等时令水果价格是否形成压制？ |
| 礼盒 | 节日动销能否消化好货库存？ |
| 出口 | 出口订单是否改变好货供需？ |

### 价格观察要点

价格分析应同时观察产区膜袋与纸袋果、不同果径和等级报价，销区批发价、走货量以及冷库出库价。单一全国均价容易掩盖优果与次果、产区与销区、新果与库存果之间的价差。

### 消费与贸易资料来源 {source}

苹果及苹果汁进出口使用[海关总署](https://www.customs.gov.cn/)数据；销区批发价可使用农业农村部重点农产品市场信息平台公开数据；渠道走货和礼盒动销来自商业调查，须注明样本市场和统计期间。

## 07 价格验证与每日跟踪 {watchlist}

苹果行情分两段：生长季（4—10月）交易产量和优果率预期，库存季（10月—次年清库）交易入库结构、出库节奏和节日消费。同一个指标在两段的含义不同，必须先确认当前处于哪个阶段。

### 价格验证链 {wide}

**天气与坐果变化 → 产量和优果率预期变化 → 开秤价和入库结构变化 → 冷库库存和出库节奏变化 → 销区现货和等级价差变化 → 基差、月差、仓单与期货价格反应**

如果盘面上涨而销区走货平淡、冷库出库偏慢，涨价可能更多由减产预期或资金推动；如果盘面下跌但好货价格坚挺、库存快速消化，则库存果的紧张可能尚未被充分定价。优果与次果的分化往往比均价方向更重要。

### 指标按频率分层 {full}

| 频率 | 指标 | 用途 |
|---|---|---|
| 慢变量 | 面积、树龄结构、品种更替、长期消费 | 确定年度供需方向 |
| 产季内 | 花量、坐果、套袋、果径、优果率 | 修正产量和质量预期 |
| 月度/周度 | 入库率、冷库库存、出库速度、出口 | 判断现货松紧节奏 |
| 日度 | 产区等级报价、销区批发价、基差、月差和持仓 | 识别预期差与交易驱动 |

### 每日跟踪 {checklist full}

| 顺序 | 检查 |
|---|---|
| 1 | 主产区天气、花量、坐果、套袋、果径与优果率 |
| 2 | 产区开秤价、客商采购、入库率和不同等级价差 |
| 3 | 冷库库存、出库速度、货权成本和剩余质量 |
| 4 | 销区到货、成交、批发价及替代水果 |
| 5 | 仓单、交割预报、基差、月差和持仓 |

### 研究口径来源 {source}

国内期货、仓单和交割数据使用[郑州商品交易所](https://www.czce.com.cn/)资料；产量趋势使用[国家统计局](https://www.stats.gov.cn/)数据。所有高频商业数据都应保留历史快照并注明发布时间，避免用后来修订值解释当时行情。

## 99 关联品种 {relations}

苹果与红枣同为生鲜交割品种，研究方法可以互相参照（坐果品质、入库率、等级结构三层筛选）；与柑橘、梨等非上市水果存在鲜食替代关系。苹果是郑商所品种中受天气驱动最强的之一，生长季的天气升水交易和库存季的去库交易是两条主线。
